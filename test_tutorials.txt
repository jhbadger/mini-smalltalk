# The tutorials, checked once rather than in both passes of test_vm: they are documentation, they are
# read in from disk on demand, and loading all of them into the image makes every later garbage
# collection slower for no gain.
# 
# What is checked: that each one reads in, that its lessons are there and have distinct titles and
# real text, and that every line of a lesson the system takes for an example can at least be compiled.
# Whether the examples ANSWER something sensible is a question only running them settles, which is the
# author's job; AbstractTutorial>>checkExamples is there for that.
Smalltalk tutorialNames class name ==> #Array
(Smalltalk tutorialNames includes: 'Smalltalk') ==> true
(Smalltalk tutorialFileFor: 'Smalltalk') isNil ==> false
(Smalltalk tutorialFileFor: 'nothing at all') printString ==> 'nil'
